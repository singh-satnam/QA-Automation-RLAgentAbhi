1. Open RG login page 
2. Enter valid "PI" email & password
3. Click Sign In
4. PI lands on 'My Projects' page successfully
5. Search of the project card which has button 'Active'
6. Click on the Active button 
7. This will display project details page 
8. you should see the following tabs on the page 
	Project Details	
	Events	
	Available Products
	My Products
	All Products
	Shared Services
9. User Click on the Project Details tab 
10. Verify following fields are displayed and have a value 
	Project Name 
	Project Description 
	Project Owner
	Created On
	Project Type
	Account Details
	Budget
11. Read the value of the Budget field 
	
12. you will see 'Actions' on the right side of the page 
13. Verify below options are displayed under Action 
	Pause
	Stop
	Sync
	Add Budget
	Archive
14. Click 'Add Budget' and on the new Dialog box type '1' in the field 'Enter the amount you would like to add to the current project budget'
15. User click on Submit
16. Validate the success message pop up "The Budget was added successfully" displays on the top right corner and disappears 
17. Validate the Budget field the updated value = Read value of Budget + 1
