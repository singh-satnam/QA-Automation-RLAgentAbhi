1. Open RG login page 
2. Enter valid "PI" email & password
3. Click Sign In
4. PI lands on 'My Projects' page successfully
5. Search of the project card which has button 'Active'
6. Click on the Active button 
7. This will display project details page 
8. you should see the following tabs on the page 
	Project Details	
	Events	
	Available Products
	My Products
	All Products
	Shared Services
9. User Click on the Project Details tab 
10. Verify following fields are displayed and have a value 
	Project Name
	Project Description
	Project Owner
	Created On
	Project Type
	Account Details
	Budget	
	Project Tags 
	Assigned Users
	Linked Studies
	Add Products 
11. Click on 'Manage' next to Assigned Users
12. Validate the admin user should not be displayed in this list
13. Click on button 'Cancel'
